# Website
We created our website using the ["Design - Responsive business website template"](https://www.myresponsee.com/free-responsive-website-templates/), which we edited to suit our needs

## Folder Structure
```text
Website/
├── css                          # All of the CSS configurations that were used for the website
├── font                         # All the fonts used for the website
├── img                          # All images and files that were used in the website
├── js                           # All JavaScript scripts that were used in the website
├── owl-carousel                 # The defintions for carousel which came with the website template
├── *.html                       # HTML File that defines how the page for a given subpage of the project works
├── LICENSE.txt                  # The license for this website
└── Readme.md                    # The file you are currently reading
```
