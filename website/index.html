Project Abstract


About

Investigating the kinds of decisions that go into choosing one image segmentation over the other, in the field of Autonomous Vehicles. We fine-tuned 2 models: SAM3, and YOLO26, and created a third simpler model for qualitative comparisons

SAM3

Traditionally an instance segmentation model, it was created by Meta. It is a heavier model with about 850 million parameters, but very good precision and the ability to 'select' what you want the model to infer on.

YOLO26

Traditionally a bounding box object detection model, currently maintained by Ultralytics. It is a lightweight model (with the largest model having about 55 million parameters), that can only infer on whatever data it was trained on. It is very fast, but not the most precise.

Results

Quantitatively both versions of SAM3 that we used were more precise than the two YOLO26 versions. However YOLO26 was 41 times faster in creating its inferences than SAM3, with YOLO26 inferring in 10.4ms and SAM3 on 427.9ms.
