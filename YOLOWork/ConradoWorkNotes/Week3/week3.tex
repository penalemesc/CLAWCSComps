\begin{enumerate}
    \item "videoStream": is our source
    \item "imgsz = 640": resizes the input to a 320x320 image (\href{https://docs.ultralytics.com/modes/train?h=arguments#train-settings}{yolo docs}). Making that number smaller improves performance significantly, but it does also mean the model will make worse predictions (since it has access to less information, since the image is shurnken using some method)
    \item "verbose = false": prevents the program from writing to terminal where and what predictions are made. It makes execution run slightly faster (needed in the context of what I was doing at the time, which is using an rpi, a not very powerful device) \href{https://docs.ultralytics.com/usage/cfg}{Yolo docs}
\end{enumerate}
